# Automatismes_DNB

Application d'entraînement pour les élèves de 3ème, dédiée à la partie « Automatismes » de l'épreuve de mathématiques du Brevet des collèges (DNB).

## Description

Application web autonome (un seul fichier HTML) permettant aux élèves de s'entraîner en autonomie sur les automatismes attendus à l'examen : calcul mental, algèbre, géométrie, proportionnalité, statistiques, etc. Les questions sont générées aléatoirement à chaque session, avec correction détaillée et figures géométriques quand nécessaire.

## Fonctionnalités

- Génération procédurale de questions (valeurs numériques renouvelées à chaque tirage, pas de banque figée).
- 15 thèmes du programme de 3ème, y compris Pythagore (théorème/réciproque) et Thalès (théorème/réciproque) traités séparément.
- Deux types de questions : réponse libre et QCM.
- Correction immédiate avec explication pour chaque question.
- Figures géométriques générées en SVG.
- Interface simple, utilisable sur ordinateur, tablette ou smartphone.

## Utilisation

Ouvrir simplement `index.html` dans un navigateur, aucune dépendance ni connexion internet requise après téléchargement.

Version en ligne : https://auriaphilippe.forge.apps.education.fr/Automatismes_DNB
